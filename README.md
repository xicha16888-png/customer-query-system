# 客户交叉查询系统 v1.2

同时查询「手机分期 MORODOK」「小贷/抵押 PAWN」，并参考静态导入的历史客户名单，避免同一个客户重复借款。

## v1.2 更新了什么：管理员面板加了「批量导入」

管理员面板（🔒 管理员 / Admin，解锁后）原来只能一条一条手动新增/修改客户记录，现在多了一个
"批量导入（Excel / CSV）"区块：

- 支持上传 `.xlsx` / `.xls` / `.csv`，在浏览器里用 SheetJS 解析（不经过服务器上传文件，纯前端读取）
- 表头随便写，只要能识别出"姓名"这一列即可（必填），另外会尝试自动识别：身份证号、性别、备注/状态、黑名单
  （中英文表头都支持，比如 `姓名`/`name`、`身份证号`/`ID Number`、`黑名单`/`Blacklist` 都能认出来）
- 有"下载模板 CSV"按钮，给不确定格式的人参考
- 上传后先弹出预览（识别到几条、前 20 条内容），确认无误再点"确认导入"才会真正写入
- 导入规则跟手动新增一致：姓名或身份证号能匹配上已有记录（或同一批次里前面的行）就覆盖更新，匹配不上就新增
- 一次最多 20000 条；整批只会写一次本地文件、只提交一次 GitHub（不会一条提交一次导致刷屏）
- 后端新增了一个接口 `POST /api/admin/bulk-upsert`（同样需要管理员密码），逻辑和原来的 `/api/admin/upsert` 共用同一份数据结构，行为完全一致，只是批量处理

## 关于历史名单的说明

- 只用于"这个人以前来过、有没有不良记录"这种参考性提示，不代表真实未结清金额
- 状态分类：`已结清(历史)` / `锁机/逾期(历史)` / `其他备注(历史)`（原表里五花八门的备注，比如"add fb"、"lose phone"等，统一归到这类）/ `无标记(历史)`
- 只有"锁机/逾期"状态会触发醒目提示，其余仅展示
